JACOB: FRONTLINE — PAGBUBUKAS NG LARO

1. I-double-click ang BUKSAN-JACOB-FRONTLINE.bat.
2. Magbubukas ang laro sa browser kapag handa na ang local server.
3. Panatilihing bukas ang window na "Jacob Frontline Server" habang naglalaro.
4. Para ihinto ang server, pindutin ang Ctrl+C sa server window.

Sa unang bukas, mag-i-install muna ito ng kailangang packages kung wala pa ang mga ito.
Kailangan ang Node.js; internet lang ang kailangan kung kailangan pang mag-install.
